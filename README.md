# Obesity Prediction & Machine Learning Analysis

This project focuses on predicting obesity levels and analyzing underlying behavioral and lifestyle factors using a combination of supervised and unsupervised machine learning techniques.

---

## Project Overview

The goal of this study is twofold:
1. **Prediction**: Classify individuals based on obesity risk.
2. **Insight discovery**: Identify hidden patterns and group structures in the data.

---

## Methodology

### Data Preprocessing
- Handled missing values and duplicates
- Encoded categorical variables
- Applied Min-Max scaling to numerical features

---

### Supervised Learning Models
Several classification models were implemented and compared:
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree
- Random Forest
- XGBoost

Each model was evaluated using:
- Accuracy
- Precision
- Recall
- F1-score

---

### Unsupervised Learning
To explore hidden structures in the dataset:
- Principal Component Analysis (PCA)
- K-Means Clustering
- Hierarchical Clustering

---

### Model Evaluation
- Cross-validation for robust performance estimation
- Hyperparameter tuning for all models
- Comparative analysis of model performance

---

## Key Features

- End-to-end machine learning pipeline in R
- Combination of supervised and unsupervised learning
- Extensive model benchmarking
- Data visualization (correlation heatmaps, distributions, variable importance)
